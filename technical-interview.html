Programming

What is the difference between a compiled and an interpreted language?

A compiled language (such as C) is translated into machine code before it runs, which usually means faster execution and some errors caught early. An interpreted language (such as Python or JavaScript) is run line by line by an interpreter, which makes testing quick but can be slower. Many languages mix both ideas: Java compiles to bytecode, which the Java Virtual Machine then runs.

Programming

What are the four pillars of object-oriented programming?

Encapsulation keeps data and the methods that use it together and hides internal details. Abstraction exposes only what is needed. Inheritance lets a class reuse behaviour from a parent class. Polymorphism lets the same method name behave differently depending on the object.

Programming

What is the difference between an array and a linked list, and between a stack and a queue?

An array stores items side by side, so access by index is fast but inserting in the middle is slow. A linked list stores nodes that point to the next one, so inserting is fast but lookup is slow. A stack is last in, first out (like undo history). A queue is first in, first out (like print jobs).

Programming

What is Big-O notation?

It describes how the running time or memory of an algorithm grows as the input grows. O(1) is constant time, O(log n) is like binary search, O(n) is one pass through a list, and O(n²) is nested loops. I use it to compare solutions, not to measure exact time.

Database

What is the difference between a primary key and a foreign key?

A primary key uniquely identifies each row in a table, such as product_id. A foreign key is a column that points to a primary key in another table, such as orders.customer_id pointing to customers.id. It links the tables and keeps the relationship valid.

Database

What is normalization?

Normalization organises tables to reduce duplicate data and update problems. First normal form (1NF) means each column holds a single value. Second normal form (2NF) removes dependence on only part of a composite key. Third normal form (3NF) removes dependence between non-key columns. The result is smaller tables linked by keys.

Database

What is the difference between INNER JOIN and LEFT JOIN?

INNER JOIN returns only rows that have a match in both tables. LEFT JOIN returns every row from the left table and fills the right side with NULL when there is no match, for example customers who have not placed an order yet.

Database

What does ACID mean?

Atomicity: a transaction happens fully or not at all. Consistency: rules stay valid. Isolation: transactions running together do not disturb each other. Durability: committed data survives a crash. In a shop, saving the order and reducing the stock should be one transaction.

Web development

What happens when I type a URL and press Enter?

The browser finds the server's IP address through DNS, opens a TCP connection (with TLS for HTTPS), and sends an HTTP request. The server replies with HTML, and the browser parses it, loads the CSS, JavaScript, and images it refers to, and renders the page.

Web development

What is the difference between GET and POST?

GET asks for data and puts parameters in the URL, so it can be bookmarked and cached and should not change anything on the server. POST sends data in the request body, which is used for forms and logins and for creating or changing data.

Web development

What is the difference between client-side and server-side code?

Client-side code (HTML, CSS, JavaScript) runs in the browser and handles display and interaction. Server-side code (PHP, Node.js) runs on the server and handles data, authentication, and business rules. I never rely on client-side validation alone, because users can bypass it.

Web development

What is responsive design?

A layout that adapts to the screen size using flexible units, CSS Grid or Flexbox, media queries, and the viewport meta tag. For example, this portfolio switches to a single column on phones.

Networking

What is the difference between the OSI model and TCP/IP?

OSI has seven layers: physical, data link, network, transport, session, presentation, and application. TCP/IP simplifies this to four: link, internet, transport, and application. The layers help locate a fault, such as a cable (physical), an IP setting (network), or a web server (application).

Networking

What is the difference between an IP address and a MAC address?

A MAC address is the hardware address of a network card and is used inside a local network. An IP address is a logical address given by the network and used to route traffic between networks. IPv4 uses 32 bits and IPv6 uses 128 bits.

Networking

What do DHCP and DNS do?

DHCP automatically gives a device its IP address, subnet mask, default gateway, and DNS server. DNS translates names such as example.com into IP addresses so people do not need to remember numbers.

Networking

What does a /24 subnet mean, and how is a router different from a switch?

/24 means the first 24 bits are the network part, so the mask is 255.255.255.0 with 256 addresses and 254 usable hosts (the network and broadcast addresses are reserved). A switch connects devices inside one network using MAC addresses. A router connects different networks using IP addresses.

Cybersecurity

What is the CIA triad?

Confidentiality: only authorised people can see the data. Integrity: data stays accurate and is not changed without permission. Availability: systems and data can be used when needed. Encryption supports confidentiality, hashing and checks support integrity, and backups and redundancy support availability.

Cybersecurity

What are some common web vulnerabilities?

SQL injection: input becomes part of the query. Cross-site scripting (XSS): injected script runs in other users' browsers, prevented by encoding output. CSRF: a logged-in user's browser is tricked into sending an unwanted request, prevented with tokens and SameSite cookies. Broken authentication: weak passwords or no multi-factor login.

Cybersecurity

What is the difference between hashing and encryption?

Hashing is one-way, so it is used to store passwords (with a slow algorithm such as bcrypt or Argon2 and a salt, for example password_hash() in PHP). Encryption is two-way with a key and protects data in transit or at rest, such as HTTPS.

Cybersecurity

What are least privilege and multi-factor authentication?

Least privilege gives users and programs only the access they need. Multi-factor authentication asks for a second proof, such as a code from an app, in addition to the password. Together they limit the damage when a password is stolen.

Engineering fundamentals

What are the phases of the SDLC, and how do Agile and Waterfall differ?

The phases are planning, requirements, design, development, testing, deployment, and maintenance. Waterfall completes each phase in order before the next one starts. Agile works in short iterations with frequent feedback, so requirements can change along the way.

Engineering fundamentals

How does Git help in a project?

Git tracks changes to files. A commit saves a snapshot, a branch lets me work on a feature separately, a merge combines the work, and a pull request asks for review before merging. GitHub hosts the repository, and this portfolio is published through GitHub Pages.

Engineering fundamentals

What are the levels of software testing?

Unit tests check small pieces such as a single function. Integration tests check that modules work together. System and acceptance tests check the whole application against the requirements. Testing early catches bugs while they are cheap to fix.

Engineering fundamentals

How do I approach debugging?

Reproduce the problem, read the error message, narrow down the cause by removing or logging parts, form a hypothesis, change one thing at a time, and test again. For example, if a PHP page shows nothing, the first place to look is the server error log.

Code: FizzBuzz

Print 1 to 15, but write Fizz for multiples of 3, Buzz for multiples of 5, and FizzBuzz for both.

for (let i = 1; i <= 15; i++) {
  let out = "";
  if (i % 3 === 0) out += "Fizz";
  if (i % 5 === 0) out += "Buzz";
  console.log(out || i);
}

The remainder operator checks divisibility. Building the string avoids a separate case for multiples of 15.

SQL: busiest categories

Which product categories have the most items?

SELECT category, COUNT(*) AS items
FROM products
GROUP BY category
ORDER BY items DESC;

GROUP BY makes one row per category, COUNT(*) counts the rows in each group, and ORDER BY puts the largest first. To keep only large groups, add HAVING COUNT(*) > 5 after GROUP BY.

Troubleshooting: no Wi-Fi connection

Problem

A computer cannot connect to Wi-Fi.

Possible causes

Disabled adapter, driver problem, incorrect IP configuration, router problem, or DNS problem.

Solution

  1. Check that airplane mode is off and the Wi-Fi adapter is enabled.
  2. Restart the adapter, then update or reinstall the driver if it still fails.
  3. Run ipconfig /all. An address starting with 169.254 means no address was received, so try ipconfig /release and ipconfig /renew.
  4. Test another device and restart the router to see whether the router is the cause.
  5. Run ping 8.8.8.8. If that works but ping google.com fails, the problem is DNS, so run ipconfig /flushdns or set another DNS server.

Lesson learned

Work from the bottom up and test one layer at a time: adapter, IP settings, router, then DNS. This finds the cause faster than changing many settings at once.
